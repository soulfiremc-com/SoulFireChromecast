# SoulFireChromeCast

SoulFire Chromecast receiver app to see live stats.

## Development

Read [CONTRIBUTING.md](CONTRIBUTING.md) for prerequisites, compatibility, validation, and pull requests.

```bash
bun install --frozen-lockfile
bun run dev
bun run typecheck
bun run check
bun run build
```
